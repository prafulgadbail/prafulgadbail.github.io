Three-Tier Application — CI/CD Pipeline Flow

Live Execution Workflow: Developer Push ➔ Controller ➔ Agent Build ➔ Security Scan ➔ ECR ➔ EKS

1. DEVELOPER / SOURCE CONTROL

Developer Git Push ➔ GitHub Webhook Triggered ➔ Jenkins Controller Notified

2. JENKINS AUTOMATION SERVER

Jenkins Controller assigns job to Jenkins Build Agent (Kubernetes Pod / EC2 Node)

3. BACKEND & FRONTEND PIPELINE EXECUTION

  • • Maven Build: mvn clean package -DskipTests
  • • SonarQube Code Quality & Gate Check Verification
  • • Trivy Security Scan: Vulnerability Assessment
  • • Docker Build & Push: Container Tagged & Pushed to Amazon ECR

4. AWS CLOUD DEPLOYMENT

kubectl rollout ➔ Amazon EKS Cluster Deployment (Backend Pods) + S3 / CloudFront CDN (Frontend)

GitOps Microservices Deployment Architecture

Declarative Continuous Delivery with GitHub Actions, Helm & ArgoCD

1. DEVELOPER COMMIT & CI BUILD

Code Commit ➔ GitHub Actions CI Pipeline Triggered ➔ Build & Push Image to ECR

2. GITOPS MANIFEST REPOSITORY UPDATE

GitHub Actions updates image tag in Helm values.yaml in GitOps Repo

3. ARGOCD AUTO-SYNC ENGINE

ArgoCD detects Git drift ➔ Pulls updated Helm Chart ➔ Syncs EKS Cluster state

4. ZERO-DOWNTIME ROLLING DEPLOYMENT
