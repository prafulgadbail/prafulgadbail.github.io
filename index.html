Project 01 Details

AWS EKS 3-Tier Enterprise Pipeline Architecture

This project establishes an end-to-end automated deployment pipeline. When developer pushes code to GitHub, Jenkins triggers build jobs, runs SonarQube quality analysis, performs Trivy vulnerability scans on Docker images, pushes the secure image to Amazon ECR, and deploys to AWS EKS via Helm charts.

Project 02 Details

GitOps Pipeline with Docker Hub & Kubernetes

Automated continuous delivery workflow. GitHub Actions builds the Docker image and pushes it directly to **Docker Hub**. Then, GitHub Actions updates the Helm values in the Manifest Repository. **ArgoCD** running inside the Kubernetes cluster detects drift and automatically syncs the live cluster with zero downtime.

1. GitHub Actions

3. ArgoCD
